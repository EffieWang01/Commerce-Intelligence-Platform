# 键盘本体与配件匹配修正

原先 `mechanical keyboard` 的前排结果包含连接线和键帽。核对真实目录与召回结果后，确认候选中存在
机械键盘本体，但当前 LambdaMART 文本匹配特征没有可靠区分商品本体与适配配件。

本次在召回之后、模型排序之前加入键盘商品类型匹配规则。根据 query 中请求的对象，以及标题中商品主体
与适配说明的位置，区分机械键盘、普通键盘、键帽、线材、手托、卫星轴、轴体和相关工具。
整把键盘附带键帽、线材或拔键器时保留为键盘；描述明确写明不含键盘时不作为本体返回。
机械手感键盘不按机械键盘处理。用户历史拼接出的个性化推荐请求不应用这层查询类型约束。

| 实际查询 | 修正后的前排结果 |
| --- | --- |
| `mechanical keyboard` | GAMDIAS Hermes E2、Blue Switch 87 键键鼠套装、Hyekit 机械键盘套件 |
| `mechanical keyboard keycaps` | PBT 键帽、NPKC 键帽等 |
| `keyboard cable` | Kraken 键盘连接线等 |
| `keyboard wrist rest` | 键盘手托 |
| `keyboard keycap puller` | VELOCIFIRE 拔键器 |

第一条查询的 30 个召回候选中，3 个符合机械键盘类型。返回这 3 个候选，不用配件填充数量。
过滤过程通过 `product_match` trace 展示目标类型、过滤前后候选数；结果理由补充对应类型。
模型权重和模型原始分数均未改变。

全套 46 项测试通过，覆盖规则/学习排序、明确的配件查询、带配件的完整键盘，以及非键盘查询。
`scripts/verify_trained_ranker.py --api-url http://127.0.0.1:8008` 同时检查真实目录中的已核对商品 ID，
验证本体查询保留 GAMDIAS，而键帽与线材查询仍保留对应配件。

该规则当前限于键盘类目，尚未推广到其他商品。规则依赖标题与描述的明确证据，不能替代商品类型标注或
完整相关性测评；此前的 ESCI NDCG 指标不包含这层新规则。中文查询跨语言召回问题也尚未在本次修正中处理。
